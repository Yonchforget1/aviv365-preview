# Aviv365 — עיצוב חדש 🎨

עיצוב מודרני, רספונסיבי ו-RTL לאתר Aviv365. **עצמאי לחלוטין** — אפשר לפתוח בדפדפן ולראות מיד, ואחר כך לייבא לוורדפרס.

## 📁 מבנה הקבצים
```
aviv365-redesign/
├── index.html        ← דף הבית
├── about.html        ← דף אודות
├── contact.html      ← דף צור קשר + טופס + מפה
└── assets/
    ├── style.css     ← כל העיצוב (צבעים, פונטים, רספונסיביות)
    └── main.js       ← תפריט מובייל + אנימציות
```

## 👀 איך לצפות בעיצוב עכשיו
פשוט **לחיצה כפולה על `index.html`** — הוא ייפתח בדפדפן. נסו גם להקטין את החלון כדי לראות את התצוגה במובייל.

## 🎨 התאמה אישית מהירה
כל הצבעים מרוכזים בראש `assets/style.css` תחת `:root`. לשינוי צבע המותג — ערכו את `--blue` ו-`--accent`. לשינוי פונט — החליפו את `Heebo` (כרגע נטען מ-Google Fonts).

נקודות שכדאי להחליף בתוכן אמיתי:
- ההמלצות בדף הבית (כרגע לדוגמה — מסומן בהערה).
- כתובת האימייל `info@aviv365.com` (אם שונה).
- מספר שנות הניסיון (`15+`) ושאר המספרים בסרגל הנתונים.
- לוגואי הטכנולוגיות / לקוחות (כרגע טקסט — אפשר להחליף בתמונות).

## 🔌 איך לייבא לוורדפרס — 3 דרכים

### דרך 1 — Elementor (הכי קל, מומלץ למי שלא מתכנת)
1. צרו עמוד חדש בוורדפרס ופתחו ב-Elementor.
2. השתמשו בעיצוב כאן כ"שרטוט" (reference) ובנו את הסקשנים מחדש בגרירה — Hero, כרטיסי שירותים, נתונים, טופס.
3. ערכת הצבעים מ-`:root` ב-`style.css` — הזינו את אותם ערכי HEX ב-Site Settings של Elementor.

### דרך 2 — Child Theme (לשליטה מלאה בעיצוב)
1. צרו תיקיית Child Theme: `wp-content/themes/aviv365-child/`.
2. העתיקו לתוכה את `style.css` (הוסיפו בראשו את כותרת ה-Child Theme הנדרשת ע"י וורדפרס).
3. את ה-HTML של כל עמוד אפשר להמיר לתבנית PHP (`page-home.php` וכו') או להדביק כ-Custom HTML Block.
4. טענו את `main.js` דרך `functions.php` עם `wp_enqueue_script`.

### דרך 3 — Custom HTML Block (הכי מהיר לדף בודד)
1. צרו עמוד חדש → הוסיפו בלוק **HTML מותאם אישית**.
2. הדביקו את תוכן ה-`<body>` של `index.html`.
3. הוסיפו את ה-CSS דרך **Appearance → Customize → Additional CSS** (הדביקו את כל `style.css`).

> ⚠️ **חשוב — WPML / שתי שפות:** האתר דו-לשוני. כל עמוד שמייבאים צריך לשכפל ולתרגם לגרסה האנגלית דרך WPML. כפתור ה-EN בתפריט הוא placeholder — לחברו ל-WPML language switcher.

> 💡 **לפני כל שינוי בוורדפרס:** עשו גיבוי מלא (UpdraftPlus) ועבדו על Child Theme — לא על התבנית המקורית.
